# Alice Dmello — Personal Portfolio

A React + Vite portfolio based on Alice Dmello's resume. It presents her education, full-stack and Python projects, AI/ML and geospatial analysis work, technical/design skills, certificates, activities, contact information, and resume PDF. It is not limited to a single job title.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In a terminal, run `npm install`.
4. Run `npm run dev` and open the local URL shown in the terminal.
5. To check a production build, run `npm run build`.

The resume is served from `public/resume.pdf`. Replace that file if the resume changes, keeping the same filename.
